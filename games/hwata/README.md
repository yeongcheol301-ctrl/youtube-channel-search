# 화타의 바다 약초 일기 — 시제품

바닷가 마을의 화타가 낮에는 바닷속에서 해초 약재를 따고 물고기를 잡고(데이브 더 다이브 방식), 밤에는 그 재료로 약을 지어 한의원을 운영하는 웹게임 시제품입니다. 기획은 Claude Docs 「명의 화타 추리 게임 기획안」을 따릅니다.

- `src/data.js` 재료·약·환자·강화 숫자
- `src/rules.js` 게임 규칙(화면 없음)
- `src/world.js` 바닷속 지도(160×120 블록), 날마다 자라는 해초·진주조개, 가라앉은 상자, 해구의 난파선
- `src/boss.js` 첫 보스 「검은지느러미」(4일째부터 해구에서 등장, 돌진을 바위로 유도해 기절시키고 작살로 지치게 한 뒤 진정시키면 난파선 입구가 열림)
- `src/quests.js` 물속 퀘스트 3개(해녀 할망, 울상인 소년, 장비)
- `src/sprites.js` 도트 그림·아이콘(물고기·화타는 코드로 그려 테두리와 움직임 프레임을 붙임)
- `src/light.js` 깊이에 따라 어두워지는 빛
- `src/audio.js` 효과음(파일 없이 합성)
- `src/game.js` 화면·조작·낮/밤 흐름
- `tests/` 규칙·지도·퀘스트·빛·보스 테스트

## 실행

```
cd games/hwata
python -m http.server 8000   # 브라우저에서 http://localhost:8000
npm test                     # 테스트
```

주소 끝에 `?debug`를 붙이면 개발자 도구에서 `window.__hwata`로 상태를 볼 수 있습니다.
