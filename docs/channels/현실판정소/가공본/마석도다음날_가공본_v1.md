## 2. 10초 구간별 새 질문

| 구간 | 새 질문 / 새 사실 |
|---|---|
| 0~10초 | 수십 명을 때린 손, 다음 날은? → 장면 소개 → "하나씩 판정" |
| 10~20초 | 마디가 부어 주먹이 안 쥐어진다(복서 너클) → 손목 앞 관절도 헐거워진다 → "그럼 뼈는?" |
| 20~30초 | 새끼손가락 쪽 손등뼈 목이 꺾인다 → 손 골절 10%, 복서 골절 → 꺾기: 손바닥이면? |
| 30~40초 | 기증된 팔 실험: 손바닥은 절반 힘에 같은 휨 → 그런데 진짜 위험한 건 반창고 |
| 40~55초 | 이빨에 긁힌 상처 → 세균이 관절·뼈로 → 의사는 "물린 상처"로 치료 → 은퇴 + 도장 |

### 3-1. 손뼈 골절 기준 (인수인계 6장 "확인 필요" 항목) — 결론

- **"몇 N(뉴턴)이면 손등뼈가 부러진다"는 기준 숫자는 찾지 못했다.** 생체역학 논문은 고정 기구 강도나 상대 비교(Horns 2015의 "55%·2배")만 있고, 펀치로 손등뼈가 부러지는 절대 기준은 없음 → **대본에 골절 기준 숫자를 쓰지 않는다.** 대신 "손 골절의 10%"(빈도)와 "절반 힘에 같은 휨"(실험 비교)을 쓴다.
- ⚠️ "실험 중 손뼈 변형은 골절 기준의 7분의 1이었다"는 검색 요약에만 나옴(원문 미확인) → 쓰지 않음.

### 3-2. 버린 문장 (쓰면 틀리거나 근거 약함)

## 7. 대표님 확인 필요

1. **제목 비교 순번**: 같은 날 「활 겨누기」도 질문형. 둘 중 이 편을 주장형(제목 B "수십 명을 때린 주먹, 다음 날 제일 위험한 건 반창고입니다")으로 돌릴지.
2. **판정 문구**: "반만 가능" 추천(한 방은 되지만 수십 명째까지 손이 못 감). 1편 존 윅 판정이 무엇이었는지 → 같으면 피함. 대안 "불가능".
3. **1편과 겹침**: 인수인계 2-4에 1편 내용으로 "맨주먹 수십 번 → 복서 골절"이 적혀 있음. 1편 최종 대본을 로컬에서 못 찾음 → **1편에서 복서 골절을 이미 말했다면** C08~C09를 짧게 줄이고 "1편에서 본 그 골절"로 넘길지.
4. **C10 손바닥 장면**: 마석도 하면 떠오르는 "손바닥 따귀" 장면과 이어 붙여 "마석도 특기, 손바닥 따귀라면요?"로 바꿀지 (⚠️ 그 장면이 실제로 시리즈 명장면인지 대표님 기억 확인 필요. 지금 대본은 작품과 무관한 일반 질문이라 안전).
5. **C11 "기증된 팔"** 표현이 거북하면 "실제 사람 팔로 한 실험"으로 바꿀 수 있음(음절 비슷).
6. 첫 씬 C01~C02 CLEAN 2~3안 확정 (제작가이드 6장).
