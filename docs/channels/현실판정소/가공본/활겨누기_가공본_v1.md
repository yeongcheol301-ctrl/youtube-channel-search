## 2. 10초 구간별 새 질문

| 구간 | 새 질문 / 새 사실 |
|---|---|
| 0~10초 | 1분 버틸까? → 영화에선 한참 협박 → 현실에선 어깨·등이 한껏 힘을 쓴다 → "그럼 얼마나 떨리지?" |
| 10~20초 | 힘쓸수록 떨림 ↑ → 정상급 궁수는 바로 쏜다 → "오래 버티면 어떻게 되지?" → 20초 반복 실험 |
| 20~30초 | 모두 더 흔들림, 오래 겨눌수록 덜 맞음 → **꺾기 1**: "컴파운드면?" (댓글 질문 그대로) |
| 30~40초 | 끝까지 당기면 무게가 빠짐, 30kg → 6kg → 오래 겨눌 수 있다 → "그럼 영화도 맞는 거 아냐?" |
| 40~53초 | **꺾기 2**: 호크아이는 리커브 → 리커브는 끝이 가장 무겁다 → 전부 팔로 버팀 → 판정 조건부 |

## 4. 선점 + 차별점

- 실행: `cli.py "활 겨누기 현실" --shorts all --days 0 ... --max-results 10 --max-per-channel 2` (약 100 units)
- 결과: **"후보 0개 검사, 조건에 맞는 영상이 없습니다."** → 이 키워드로는 경쟁 쇼츠가 안 잡힘. 키워드가 좁았을 가능성 있음(⚠️ "호크아이 활", "활 시위 버티기"로 한 번 더 돌리면 약 100 units 추가).
- 알려진 같은 각도 영상: 대표님이 가져온 원본 "영화처럼 활을 겨누며 상대를 위협하는게 현실에서도 가능할까??" **125만 회** 1편. 수십만 회 영상이 여러 개 있는 상태는 아님 → 각도는 유지하되 아래로 차별.
- 우리 차별점
  1. 원본이 남긴 **댓글 질문(컴파운드면? 호크아이는 리커브인데?)에 정면으로 답하는 후속편** 구조. 질문은 검증된 것, 답은 우리 것.
  2. 같은 더미가 **리커브 → 컴파운드 → 리커브**로 활을 바꿔 들며 몸이 겪는 차이를 보여줌 (떨림 vs 차분).
  3. 실제 실험 재현: 20초 버티기 반복 → 모두 흔들림.
  4. 호크아이 활 종류를 제조사 쪽 자료로 확인 (팬 추측이 아님).

## 5. 판정

**판정: 조건부 가능 (노랑)**
- 컴파운드 활: 끝에서 붙잡는 무게가 1/5 안팎으로 줄어 오래 겨눌 수 있다 → 가능 쪽
- 리커브 활(호크아이가 든 활): 당긴 무게 전부를 팔·등으로 버텨야 하고, 20초 반복만으로 흔들림이 커진다 → 1분 협박은 무리
- 도장 위 금색 태그: "리커브 vs 컴파운드" / 체크리스트: "✓ 컴파운드 활" "× 리커브 활"
- ⚠️ 최근 편 판정과 겹치는지 확인 필요 (피드백로그에 판정 칸이 없어 확인 못 함)

## 8. 대표님 확인 필요

1. **제목 A/B** (A 추천: 숫자 "1분" + 몸 "팔" 포함).
