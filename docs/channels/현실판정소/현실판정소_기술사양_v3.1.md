## 4. 자막
- 폰트: G마켓 산스 Bold (ASS Fontname `G마켓 산스 Bold`, 파일 `shared\hyunsil_judge\fonts\GmarketSansBold.otf`), 크기 74.
- 한 줄이 1000px 넘으면 그 줄만 크기 축소(\fs68~72).
- 위치: 매 줄 `{\an5\pos(540,1300)}`. 흰색, 외곽선 2.5, 그림자 1.5 (BackColour &HA0000000), 줄마다 `\blur1`.
- 한 번에 한 줄, `\N` 금지, WrapStyle 2, **약 13자 이내**(크기 74에서 한글 1자 ≈ 74px, 14자면 1,000px를 넘어 매번 축소됨. 띄어쓰기는 좁으니 실제 폭은 렌더로 확인). 긴 문장은 말이 끊기는 곳에서 다음 자막으로.
- 쉼표·가운데점(·) 금지 (TTS 대본의 쉼표는 유지).
- 타이밍: 0.00초부터. 시작 = 그 말 시작점, 끝 = 다음 자막 시작(공백 0). 실제 오디오에서 silencedetect(-40dB, 0.12초) 또는 10ms RMS로 측정. 마지막 자막은 영상 끝까지.

## 7. 소리
- TTS: AI Studio, 목소리 Riko. 스타일: "Fast-paced Korean YouTube Shorts science narrator. Speak quickly, about 7 syllables per second, no long pauses between sentences. Confident, tense, documentary tone. Only a brief beat before the final verdict."
- 출력 속도 6.6~7.0음절/초. 길이는 실제 TTS로 계산(예상치 금지). WAV 헤더 수정: byteRate 48000, blockAlign 2, data 크기 재계산.
- BGM: `shared\hyunsil_judge\bgm\_사용곡\`. 우주 = BGM_우주_거대 / 물·자연 = BGM_수중_자연 / 추격·위험 = BGM_긴장_액션 / 애니·동화 = BGM_동화_애니 / 애매하면 BGM_기본_D.
- 체인: BGM volume 0.6, sidechaincompress ratio 4, threshold 0.05, 최종 loudnorm -14 LUFS(스테레오). BGM이 길면 끝 1.3초 페이드아웃. 변경 뒤 ebur128로 다시 측정.
