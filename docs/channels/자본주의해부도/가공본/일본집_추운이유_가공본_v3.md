# 자본주의 해부도 가공본 v3: 일본 집이 유독 추운 이유 (2026-11-02 대표님 확정)

> **대본 확정 (11-02).** 남은 확인: ① C05 "나무로 지은 단독주택" 목조 비율 원문(총무성 통계) ② 통념 단계 생략은 가이드 예외로 기록. 다음 단계는 CLEAN 3컷 시험(C01·C06·C07).

> v2 → v3: 기존 영상(205만·170만)이 "슴슴"했던 걸 메우는 **무기 2개**를 넣었다.
> ① **그림 무기**: 한국 아파트 벽 vs 일본 나무 집 벽 **나란히 해부 컷** (꽉 vs 텅). 다른 채널엔 없는 우리 브랜드 그림.
> ② ~~한국 비교 숫자(40년 늦음)~~ → 11-02 본문에서 뺌. "작년 4월에야 의무"는 설명란·고정 댓글로.
> 11-02 수정: **C02 통념("여름이 습해서") 삭제 — 가이드 5장 ② 예외, 대표님 확인 필요.** 이유: 대본 어디서도 뒤집히지 않는 통념이라 꺼내 놓고 버려두는 문장이 됨. C03 "집이 아니라 사람을 데운다"가 "추우면 집을 데운다"는 상식을 깨는 역할을 대신함. 컷 번호는 바꾸지 않고 C02만 비움.
> 11-02 수정: C11→C13 사이에 "헌 집 값은 따뜻함이 아니라 나이로 매긴다"(C12)를 넣어 꺾기의 이유를 채움.
> 원칙(11-02): 질문은 검증된 것, 답과 그림은 우리만의 것.

## 2. 10초 구간별 새 질문
| 구간 | 새 질문 / 새 사실 |
|---|---|
| 0~10초 | 왜 추운가? → 집이 아니라 사람을 데운다 (반전 3초대) → 열이 벽으로 빠져나가서 (추운 이유 1차) |
| 10~20초 | 코타츠·담요·욕조 → "벽을 잘라 보면" → 한국 벽 꽉 vs 일본 벽 텅 |
| 20~30초 | 왜 텅 비었나? → 20년 남짓이면 건물값 0원 → 헐고 땅만 판다 |
| 30~40초 | 꺾기: 따뜻하게 지어 비싸게 팔면? → 헌 집 값은 따뜻함이 아니라 나이로 매긴다 → 단열재 값도 0원 |
| 40초~ | 엔딩 (추운 집 = 벽 대신 사람을 데우기로 한 계산) |

- **설명란·고정 댓글로 옮김 (11-02 결정)**: "참고로 일본은 작년(2025년) 4월에야 새 집 단열이 법으로 의무가 됐습니다." 본문에서는 뺐다. 이유는 C13에서 답이 끝나고, 법 이야기가 엔딩 힘을 뺐기 때문.
