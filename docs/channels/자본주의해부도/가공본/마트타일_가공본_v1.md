# 자본주의 해부도 가공본 v1: 마트 바닥 타일이 유독 작은 이유 (2026-11-02)

> **추측형** 편이다(가이드 5장, 인수인계 3-4). 근거는 교수 한 명의 인터뷰 주장뿐이고 실험 데이터·한국 마트 사례는 없다.
> 원칙: **물리적으로 맞는 부분(작은 타일 → 1미터당 이음매 많음 → 딱 소리 빨라짐)은 단정**, **마트의 의도는 끝까지 추측**으로 남긴다. "마트가 일부러 이렇게 만들었습니다"라고 말하지 않는다.
> 무기 2개: ① **소리로 여는 첫 장면**(0.00초부터 카트 바퀴 딱딱딱). ② **해부 컷**: 바닥을 잘라 카트 바퀴가 타일 이음매를 넘는 순간을 보여준다. 기존 영상(1천대 조회)에는 없는 그림.
> 실제 연구 2개로 받친다: 바닥 줄 간격 실험(2016, 걸음 속도) + 느린 음악 실험(1982, 매출). **둘 다 타일 소리 실험은 아니다**. 대본에서도 그렇게 말한다.

## 5. 제작 전 체크

1. 숫자 출처 ✅ (38%만 ⚠️ 원문 확인 필요)
2. 제목 질문에 답함 ✅ 단, 답은 "이런 주장이 있다 + 물리 원리 + 관련 실험"이고, 의도는 단정하지 않음
3. 피·사망·브랜드 외형·얼굴·눈알 없음 ✅ (카트·와인병·스피커 모두 로고·라벨 없음)
4. 비유 연출 없음 ✅ "메트로놈"은 말로만, 화면은 실제 바퀴·타일
5. 공식 문장 반복 없음, 엔딩 한 줄 + 추측형 질문 ✅ ("다음에 마트 가면 보세요"는 매 편 반복 금지라 뺐다)
