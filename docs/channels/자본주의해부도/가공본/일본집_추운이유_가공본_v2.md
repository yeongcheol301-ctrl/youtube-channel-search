# 자본주의 해부도 가공본 v2: 일본 집이 유독 추운 이유 (2026-11-02, 대표님 확정 전)

> 기준: 자본주의해부도_제작가이드_v2.1. 컷표는 "무엇이 보이는지"만.
> **v1 → v2 바꾼 이유:** v1은 숫자 6개(32·67·81·22·20·2025)라 공부하는 느낌, "헐" 순간이 없었다.
> v2는 ① 한국과 반대인 장면 "일본은 집이 아니라 사람을 데운다"를 앞에 두고 ② 숫자는 **"20년이면 0원" 하나**만 남기고 ③ "작년에야 의무"를 마지막 반전으로 쓴다.
