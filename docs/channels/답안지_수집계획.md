# 답안지 수집 계획 (2026-11-02)

> 목적: 우리 채널 18편만으로는 "무엇이 터지나"를 판단하기 어렵다. 비슷한 채널의 **떡상 영상과 저조한 영상을 함께** 모아 소재 규칙(제작가이드 3장 가설)을 확인한다.
> 도구: 이 저장소의 채널 서치 앱(`cli.py`). 필요한 것: 환경 변수 `YOUTUBE_API_KEY`.

## 1. 키워드

### 현실판정소 (영화 장면 × 현실)
| 묶음 | 키워드 | 확인할 가설 |
|---|---|---|
| 기본 | 영화 현실 가능, 영화 장면 현실, 영화 고증 | 이 장르의 떡상 기준선 |
| 실제 사례 | 영화 실제 사건, 영화 실험 해봤다 | 실제 사례·실험이 더 잘 되나 |
| 몸 | 영화처럼 하면 몸, 액션 영화 현실 | 몸 소재가 더 잘 되나 |
| 판타지 계산 | 히어로 현실 계산, 만화 현실 가능 | 판타지 계산이 정말 약한가 |
| 협찬 각도 | 재난 영화 현실, 자동차 사고 실험 | 협찬과 맞는 소재의 반응 |

### 자본주의 해부도 (생활 속 돈 계산)
| 묶음 | 키워드 | 확인할 가설 |
|---|---|---|
| 기본 | 이유를 아시나요, 숨은 이유, 알고 보면 | 통념 뒤집기 제목의 기준선 |
| 건물·공간 | 건물 숨은 이유, 아파트 비밀, 건축 비밀 | 신비한 건축사전 패턴 재확인 |
| 돈 | 돈 버는 구조, 가격의 비밀, 자영업 비밀 | 돈 숫자가 있는 소재 반응 |
| 롱폼 각도 | 부동산 숨은 이유, 세금 이유 | 롱폼·금융 협찬 가능성 |

## 2. 실행 방법 (키워드마다)
```bash
python cli.py "<키워드>" --shorts shorts --days 365 --min-subscribers 1000 --min-views 0 \
  --ratio-threshold 0 --priority views --max-results 50 --max-per-channel 3 \
  --csv-output docs/channels/answer_sheet/<키워드>.csv
```
- `--ratio-threshold 0`, `--min-views 0`: 저조한 영상도 남겨야 비교가 된다.
- 롱폼 묶음은 `--shorts long`으로 한 번 더.
- API 사용량: 키워드 1개 검색에 100 units 이상 쓴다(무료 하루 10,000 units). 하루 30~40개 이내.

## 3. 분석 방법
1. 영상마다 **구독자 대비 조회수 비율**로 상위 20% = 떡상, 하위 50% = 저조.
2. 제목을 우리 소재 유형(실제 사례 / 몸 / 판타지 계산 / 확인형 / 통념 뒤집기 / 돈 숫자)으로 분류.
3. 유형별 떡상 비율 비교 → 제작가이드 3장 가설을 유지·수정.
4. 결과는 이 파일 아래 "결과"에 표로, 결론은 1줄로.

### 주의할 점
- 검색 키워드에 들어간 단어가 제목에도 들어가서, 유형 비율이 키워드 선택에 끌려간다(예: 해부도는 거의 다 '통념 뒤집기').
- 예능·드라마 클립 채널이 섞였다. 특히 '알고 보면', '고증'의 떡상 상위는 예능 클립이 많다.
- 구독자 1~5천 명 채널은 비율이 크게 튄다. '몸'은 10편뿐이라 참고만.

**결론(1줄)**: 현실판정소는 "실제 사례·실험·고증"이 떡상 비율이 높고 "현실에서 가능할까?" 확인형 제목은 가장 약하다 → 가설 중 '판타지 계산은 약하다'는 유지(15%), 제목은 주장형 유지 근거 추가. 해부도는 유형 간 차이가 작아 가설 수정 보류, 키워드로는 "돈 버는 구조·건물 이유"가 강하고 "부동산·자영업·이유를 아시나요"는 약하다.

## 5. 떡상 영상 댓글 반응 (ego-browser, 2026-11-02)
채널별 우리 장르와 맞는 떡상 6편씩, 영상마다 상위 댓글 20개. 원본: `answer_sheet/comments/top12_comments.json`.

### 현실판정소 (주성치 당구, 정찬성 만화 기술, 이정재 등장씬 고증, 존윅 밀리터리 고증, 복싱 만화 기술, 스파이더맨 슈트)
- **"제일 안 될 것 같은 게 됐다"가 좋아요 1위**: 정찬성·복싱 만화 편 모두 '한눈팔기'가 제일 세게 먹힌 장면에 댓글이 몰렸다(좋아요 1.9만). → 결과가 예상과 반대로 나오는 순간이 핵심. 가이드 3장 "한 줄 반전"과 같다.
- **판타지도 "직접 해보면" 터진다**: 만화 기술(판타지)인데 실제 선수가 해본 영상은 떡상. 약한 건 판타지 소재가 아니라 "계산만 하고 끝나는" 방식이다. 가이드 3장 '피할 것' 문구와 맞다.
- **아는 사람이 보충하는 댓글이 많다**: "존윅이 약실 확인하는 건 그 총이 첫발 걸림이 있는 모델이라서", "상대 배우가 실제 프로였다". 디테일 하나를 던지면 댓글에서 설명이 이어진다.
- **고증 vs 멋 논쟁**: "고증 같은 건 간지 앞에 아무것도 아니다"(9.7천) vs "실제 수양대군은 저렇게 나대지 않았다"(6.5천). 의견이 갈리는 소재가 댓글을 키운다.

### 자본주의 해부도 (지진 건물, 배달 삼겹살 월 8천, 로또 세금, 아파트 밑 비밀, 코스트코 가격 숫자, 비 오면 깨끗해지는 건물)
- **"이런 원리였구나" + 내 경험담**: 지진 편은 "고층이 무조건 위험한 건 아니었네", 포항 지진 경험담. 일본 건물 편은 "그래서 반짝거렸구나". 통념이 깨지고 자기 기억과 이어질 때 반응이 크다.
- **바로 써먹는 정보는 저장·공유형 댓글**: 코스트코 가격 끝자리(90 정가 / 70 할인 / 별표 단종) 정리 댓글이 위로. 시청자가 직접 요약해 준다.
- **분노형은 댓글 수는 크지만 위험**: 로또 세금(1,928개)·아파트 비리(2,786개)는 정치·공분 댓글로 흘렀다. 가이드 '피할 것'(정치)과 충돌하므로 따라 하지 않는다.
- **전문가 정정 댓글이 많다**: 광촉매 코팅 "청소 수준 효과는 없다", 코스트코 "별표가 꼭 단종은 아님", 삼겹살 "제목이 자동화만 하면 잘되는 것처럼 썼다". 과장하면 바로 지적받는다 → 팩트체크 필수 규칙의 근거.

### 커뮤니티 검색 확인
- 에펨코리아·디시 통합검색으로 "현실에서 가능", "영화 고증 오류", "하는 이유 아는 사람"을 찾아봤으나 게임·축구 글이 대부분이라 소재 찾기용으로는 효율이 낮다.
- 쓸 만한 예: 디시에 "토르 망치 조종이 현실고증 오류냐" 논쟁 글(10월 24일). 우리 묠니르 편이 잘 된 것과 이어진다.
- **반응 검증은 커뮤니티 통합검색보다 "같은 장면을 다룬 쇼츠의 댓글"을 먼저 보는 게 빠르다.** 커뮤니티는 영화·밀리터리 갤러리처럼 장르 게시판을 정해서 본다.
