## 1. 끝난 일
- 제작 문서 수정본: `현실판정소/*_v3.1.md`, `자본주의해부도/*_v2.1.md`, 피드백로그 2개, `00_띵킹렌즈_분석_두채널.md`.
  - 소재 규칙을 '가설'로 표시(근거가 사실상 원티드 1편, 반대 사례: 묠니르·터미네이터2·타이타닉)
  - 제목 질문형/주장형 시험 판정: 차이 10%p 이상이면 고정, 미만이면 주장형 유지
  - "무슨 일인지는 첫 컷에, 왜 그런지는 끝에"
  - 수익 렌즈에 "협찬·롱폼으로 이어지나" 칸 / 성과표에 공유·댓글·구독 칸
  - 자막 약 14자 → 약 13자 / 대표님 "확정" 지적은 1회라도 즉시 반영
  - 쇼츠 광고 수익 추정: 1,000회당 약 50~150원 → 2단계(90일 1,000만 회) 채워도 월 약 17~50만 원. 돈은 협찬·해부도 롱폼에서.
- PC 원본 폴더에 옮길 때: 기존 v3/v2 파일은 `_archive\`로, 이 파일들로 교체.

## 2. 남은 일 (순서대로)
1. **답안지 수집 (ego-browser 또는 채널 서치 앱)**: `답안지_수집계획.md`의 키워드 22개.
   - 쇼츠, 올해 업로드, 한국, 키워드당 40~50편. 칸: 키워드 / 제목 / 채널 / 구독자 / 조회수 / 업로드일 / 링크.
   - 저조한 영상도 같이 남긴다(비교용). 구독자 대비 조회수 상위 20% = 떡상, 하위 50% = 저조.
   - 제목을 소재 유형(실제 사례 / 몸 / 판타지 계산 / 확인형 / 통념 뒤집기 / 돈 숫자)으로 분류 → 유형별 떡상 비율 → 가이드 3장 가설 유지·수정.
   - 클라우드에서 실패한 이유: 키 없음, Apify 월 한도 초과, 썸트렌드 크레딧 부족.
2. **제안 규칙 2개를 가이드에 넣을지 결정** (아직 미반영, 사용자 결정 대기)
   - "터지면 48시간 안에 후속": 한 편이 평소의 5배(현재 약 7,500회)를 넘으면 같은 틀 후속 1~2편을 우선 제작. 근거: 사용자 경험("터지는 영상은 결국 터진다"), 원티드 1편이 전체 조회의 32%.
   - "반응 검증 단계": 소재 고르기 통과 조건에 "커뮤니티에서 이미 반응이 확인됐나" 추가. 현실판정소는 영화 고증·옥에티·"현실이면" 글, 해부도는 "~하는 이유 아는 사람?" 질문글. 내용만 참고하고 문장은 새로, 팩트체크 필수.
3. **나루토 채널 사례 듣기**: 사용자가 예전에 나루토 명장면 + 커뮤니티 분석(이스터에그·공감 내용)을 대본화해 사진·gif로 만든 채널을 운영했음. 어떤 편이 왜 터졌는지 듣고 지금 두 채널과 공통점을 뽑는다.
