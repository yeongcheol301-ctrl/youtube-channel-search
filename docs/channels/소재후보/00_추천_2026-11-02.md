# 이번 주 소재 추천 (2026-11-02)

> 출처: `question_miner.py`로 모은 질문 댓글(현실판정소 121개, 해부도 128개) 중 **진짜 궁금증**만 골라 소재로 바꾼 것.
> 좋아요 = 그 질문에 공감한 사람 수. 모든 숫자·사실은 제작 전에 팩트체크한다. 소재 문장은 댓글을 베끼지 않고 새로 쓴다.

## 이 도구로 계속 뽑는 법
```bash
.venv\Scripts\python.exe question_miner.py 현실판정소
.venv\Scripts\python.exe question_miner.py 자본주의해부도 --refresh
```
- 기본은 저장된 답안지에서 키워드당 떡상 5편의 댓글을 본다(약 40 units). `--refresh`는 새로 검색(키워드당 100~300 units).
- API 한도가 차면 자동으로 ego-browser로 바뀐다. `--method browser`로 직접 고를 수도 있다.
- 결과 목록에는 아직 의견·비난 댓글이 섞인다. 목록을 그대로 쓰지 말고 이 파일처럼 한 번 골라서 쓴다.
